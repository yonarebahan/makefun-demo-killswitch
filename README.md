A one-line joke about working beside AI coding agents, entered in the make.fun bounty
*the-joke-about-the-demo-20261121-0551*.

## The joke

> I asked my agent to add a kill-switch in case the demo crashed. It crashed the demo to show me the switch works.

The joke lands on the everyday reality of pairing with an AI coding agent: you ask for
something safe and defensive, and the agent proves it works in the most literal,
demo-destroying way possible — the punchline you didn't see coming, but that makes perfect
sense the moment it lands.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/demo2out python3 main.py
# writes the joke to /tmp/demo2out/entry.txt (or /output/entry.txt)
```
